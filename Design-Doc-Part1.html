Location Tracking

GPS is captured at two mandatory checkpoints:

📍 Checkpoint 1: Customer Visit

Salesman taps "Check-in" when visiting. GPS + timestamp logged. Admin sees on map.

📍 Checkpoint 2: Order Placement

GPS auto-captured on "Place Order". Coordinates stored with the order record.

Both events queued for sync if offline. Admin can view all salesman locations on an interactive map.

Offline-First Architecture

Salesmen in remote areas must work without internet. The app caches all data locally and queues operations for later sync.

DataCached?Create Offline?Edit Offline?

Customers✅ Full list✅ Queued❌
Orders✅ Own orders✅ Queued❌

Sync Flow

ONLINE → App fetches latest data from API → Caches to SQLite GOES OFFLINE → Salesman browses products (from cache) → Adds new customer → saved to SQLite + SyncQueue → Places order with GPS → saved to SQLite + SyncQueue → UI shows 🟡 "Pending Sync" badge BACK ONLINE (auto-detected via expo-network) → Sync Engine pushes queued ops (POST /api/sync/push) → Server processes, returns server IDs → Server triggers SignalR → Admin notified instantly → App pulls latest data (GET /api/sync/pull?since=timestamp) → UI shows 🟢 "Synced" badge

Conflict Resolution

  • Server wins for product/stock data (Admin is source of truth)
  • Append-only for orders and location logs (no conflicts possible)
  • UUID dedup — each operation has client-generated UUID to prevent duplicates
  • Sync status shown in app: 🟢 Synced | 🟡 Pending | 🔴 Failed

GST Engine — Full Indian Compliance

Tax Logic

Intra-State (Within Gujarat)

Place of Supply = Gujarat → CGST (half) + SGST (half)
Ex: 18% GST → 9% CGST + 9% SGST

Inter-State (Outside Gujarat)

Place of Supply ≠ Gujarat → IGST (full rate)
Ex: 18% GST → 18% IGST

Per-Product GST Rates

ProductHSNGST%Intra (GJ→GJ)Inter (GJ→MH)

Pressure Cooker761518%9% CGST + 9% SGST18% IGST
Plastic Container392412%6% CGST + 6% SGST12% IGST
