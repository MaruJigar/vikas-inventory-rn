Mobile Investment & Maintenance

Option A: Standard Plan

  • One-Time Setup Cost: Rs 70,000
  • Yearly Maintenance: None required (One-time only).
  • Features Included: Core app functionality, order generation, text-based product listing, customer dataset, basic location registering. Data is retained for 1 month only (auto-deleted via MongoDB).

Option B: Advanced Plan

  • One-Time Setup Cost: Rs 1,10,000
  • Yearly Maintenance: Rs 20,000 / year (starts from the 2nd year)
  • Features Included: Everything in Standard PLUS Product Image Support, Personalized Product Catalogue (with printable CDR file), Unlimited Data Storage, and Playstore Hosting.

Option C: Premium Plan

  • One-Time Setup Cost: Rs 1,50,000
  • Yearly Maintenance: Rs 20,000 / year (starts from the 2nd year)
  • Features Included: Everything in Advanced PLUS Dedicated Distributor Login & Module, and Comprehensive Salesmen Tracking History. (Playstore Hosting Included).

Standard Terms

  1. Deployment: Delivered via private sideload APK installation (Standard Plan) or distributed via Playstore (Advanced & Premium Plans).
  2. Payment Structure: To be mutually agreed upon prior to project initiation.
  3. Agreement Duration: All options listed above are structured under a 5-Year Use Agreement.
