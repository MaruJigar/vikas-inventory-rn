Implementation Timeline (6 Weeks)

Phase 1: Backend Core — Week 1–2

ASP.NET project setup · EF Core + SQL Server · JWT Auth · CRUD APIs (Users, Customers, Products, States) · Orders API with SignalR trigger · GST Calculator Service · Seed 36 Indian states

Phase 2: Offline & Sync Engine — Week 2–3

Local SQLite schema (expo-sqlite) · Sync engine: queue → push → pull · Network detection + auto-sync · UUID dedup & conflict resolution · Sync status UI indicators

Phase 3: Frontend Integration — Week 3–4

API service layer with JWT interceptor · Connect 11 existing screens to API · Build 5 new screens · GPS capture flow (visit + order) · SignalR client on Admin dashboard

Phase 4: GST Billing & Notifications — Week 4–5

Full GST invoice generation (CGST/SGST vs IGST) · Per-item HSN + tax rates · QuestPDF rendering · Amount in words · FCM push setup · Dual notification system

Phase 5: Polish & Deploy — Week 5–6

UI polish & animations · Offline + online testing · Deploy API to VPS · Production DB + backups · EAS Build → APK · Client UAT · Play Store (optional, $25)
